# Modeller marketing hero

These paired assets are the canonical Modeller marketing hero:

- `modeller-hero-light.png` for light surfaces.
- `modeller-hero-dark.png` for dark surfaces.

Use a responsive `<picture>` element when the host supports colour-scheme media
queries. Use the light version as the default social-preview image because most
social crawlers do not negotiate a colour scheme.

Preserve the wording, composition, proportions, and architecture-layer labels.
Derivative campaign artwork should reuse the warm paper/deep ink, teal, and mint
palette and the transformation-from-model-to-layers visual motif.
