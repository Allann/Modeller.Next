title: Getting started
description: Install Modeller and take a definition from an empty folder to automatic generation.
---

There are two starting points, depending on where you are.

If you have a change request and no decision yet, start a Discovery Session in
the browser at [modeller.website](https://modeller.website) — nothing to install.

If a technology intervention is already chosen, follow the System Design
lifecycle below: install the global tool, create an RML definition in VS Code,
validate it, generate a project, and keep generated output current as
definitions change.
