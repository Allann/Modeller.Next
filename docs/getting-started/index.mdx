Modeller is an implemented, modular modelling system for preserving domain
meaning and turning validated models into deterministic outputs. The current
toolchain includes RML and SAF parsing, semantic validation, rules,
projections, configuration, template packs, generation, safe output ownership,
CLI workflows, and editor integration.
