# Project status and next steps

The reconstruction backlog has been implemented through explicit module seams.
The documentation now describes those accepted interfaces directly rather than
maintaining a second, speculative roadmap.

Use these sources for current status:

- [Reference documentation](/docs/reference) for implemented contracts and workflows.
- [Architecture decisions](/docs/architecture/decisions) for accepted design authority.
- [Migration inventory](/docs/migration/inventory) for the disposition of legacy capabilities.
- [GitHub issues](https://github.com/Allann/Modeller.Next/issues) for remaining and newly proposed work.

Release publishing, marketplace publication, and additional template packs are
delivery work rather than missing semantic contracts. Their live status belongs
in GitHub so this guide does not become a competing backlog.
