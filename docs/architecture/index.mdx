The successor is reconstructed as a set of deep modules: each module exposes a
small interface while hiding the complexity of parsing, validation, planning,
generation, or external integration behind that interface.

The legacy architecture documents are retained as design evidence. They are not
automatically authoritative; accepted decisions will move into the canonical
architecture and decision records as Wayfinder work progresses.

## Current foundation

The accepted foundation is [behaviour-first](/docs/concepts/ubiquitous-language#behaviour),
with a Modeller-owned canonical semantic model, typed rule expressions,
immutable context snapshots, pure explained evaluation, explicit lifecycle
governance, deterministic persistence, and diagrams as projections. Executable
validation, conformance, compatibility, security, and explainability evidence
guards every implementation of those contracts.

Read the [architecture decisions](/docs/architecture/decisions) for their full
status, consequences, and source evidence. Terms used by those decisions are
collected in the [ubiquitous language](/docs/concepts/ubiquitous-language).

The decisions have been translated into the live
[implementation handoff](https://github.com/Allann/Modeller.Next/issues/23).
[Architecture 101](/docs/architecture/architecture-101#implementation-handoff)
summarises the dependency sequence and first Child Care vertical slice without
duplicating the GitHub backlog.
