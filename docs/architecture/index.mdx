The successor is reconstructed as a set of deep modules: each module exposes a
small interface while hiding the complexity of parsing, validation, planning,
generation, or external integration behind that interface.

The legacy architecture documents are retained as design evidence. They are not
automatically authoritative; accepted decisions will move into the canonical
architecture and decision records as Wayfinder work progresses.

## Current foundation

Two decisions currently constrain the successor architecture:

- The successor preserves Modeller's
  [behaviour-first](/docs/concepts/ubiquitous-language#behaviour) intent and
  useful legacy decision
  [capabilities](/docs/concepts/ubiquitous-language#capability), but rebuilds
  them behind a Modeller-owned semantic model.
- Modeller owns its versioned, statically typed expression representation and
  readable authoring language. Interpreters, generated code, host languages, and
  external decision formats do not own domain meaning.

Read the [architecture decisions](/docs/architecture/decisions) for their full
status, consequences, and source evidence. Terms used by those decisions are
collected in the [ubiquitous language](/docs/concepts/ubiquitous-language), where
the remaining vocabulary work is tracked explicitly.
