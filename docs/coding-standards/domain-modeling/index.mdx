---
title: Domain Modeling
description: How domain state and behaviour should be shaped so invalid states cannot exist.
---

These standards govern how a domain concept becomes a type: where behaviour lives, how invariants
are protected, and how to avoid the anemic, flag-driven models that push logic into services and
callers instead of the type itself. Apply them whenever defining or reworking an entity, aggregate,
or value object.
