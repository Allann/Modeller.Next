---
title: Working with AI Assistants
description: Writing effective AI-facing coding instructions and verifying what an AI assistant produces.
---

These standards cover writing concise, rule-based instructions for AI coding assistants, and
verifying an assistant's own claims about the code it generates rather than trusting them
outright. Apply them when authoring skills/instructions for LLMs, or when reviewing AI-generated
code.

- [Verify AI-Generated Code's Claims Instead of Trusting Its Self-Description](/docs/coding-standards/ai-assisted-development/vibe-coding)
- [Write Concise, Rule-Based AI Coding Instructions](/docs/coding-standards/ai-assisted-development/copilot-instructions)
