# CLI

The current command-line interface provides four stable workflows:
`init`, `validate`, `plan`, and `generate`.

Read the [Modeller CLI reference](/docs/reference/modeller-cli) for installation,
arguments, output formats, exit codes, and examples. This route remains as a
compatibility entry point for links that previously targeted the legacy CLI
catalogue.
