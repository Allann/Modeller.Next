The **Child Care** definition is Modeller's canonical reference project. It is a
large, realistic domain covering entities, values, shared definitions, enums,
flags, commands, queries, keys, services, and projections.

The current definition lives at
[`samples/child-care`](https://github.com/CSharp-Catalyst/Modeller/tree/main/samples/child-care)
in the legacy repository while implementation capabilities are reconstructed in
the successor.

## What the reference project is for

- Demonstrating the modelling language with connected, realistic concepts.
- Exercising parsing and domain loading across the complete definition set.
- Verifying generation plans and rendered output at representative scale.
- Providing stable examples for documentation, editor tooling, and AI-assisted modelling.

Small examples may still be used to explain one syntax feature at a time, but
Child Care is the integration reference and source of end-to-end acceptance examples.
